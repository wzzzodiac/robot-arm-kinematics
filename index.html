MODEL NOTE

What changed in v3?

Collision detection now checks each robot link against rectangular obstacles before and during motion. Teach Mode stores joint-space poses including gripper state, then replays them as a simple industrial-style sequence. The collision guard stays active during automatic pick-and-place and taught programs, so the browser robot can finally refuse bad engineering decisions.
