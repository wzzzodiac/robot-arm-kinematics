MODEL NOTE

A real model. A planar world.

The 3D arm follows the same analytic 2R / 3R solver as the plan view. Height is presentation only: collision checks use thick line segments against XY rectangles. This is an educational kinematics studio, not a physical robot controller. Teach up to eight poses and replay your own choreography.
